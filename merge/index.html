东上联日数据汇总

整合「航班数据统计」与「航班运量汇总」：导入 FIOS 航班表、录入运量，一键生成东上航 / 联航 / 总表三行数据，逐行复制到共享文档。

🧮
📘 规则说明 ▾
  • 整合来源：本页同时替代「航班数据统计」(stats) 与「航班运量汇总」(summary) 两个工具。东上航 / 联航共用 24 列表（放一块），总表列序不同单独成块；两者分别对应共享文档《2026东上联数据汇总（新）》的三个 sheet。导出时整合到一个 Excel（两个 sheet）。
  • 自动列（来自航班数据统计）：特服（轮椅 / 无陪）、进港架次（国内/国际）、出港架次（国内/国际）、总航班量、出港调时情况航班、计划性取消航班 —— 由导入的 FIOS Excel 自动计算。
  • 自动列（来自航班运量汇总）：国内国际 / 国际出港旅客总人数、国内国际 / 国际托运总件数、出港客座率、国内国际 / 国际进港人数、国内国际 / 国际进港行李 —— 由下方手录的东航 / 上航 / 中联航运量自动汇总（东上航 = 东航 + 上航，联航 = 中联航，总表 = 东上航 + 联航）。
  • 手填列（黄色，需你补录）：收费总数、出港保障延误架次、出港不正常航班架次、始发 / 起飞正常率、当天临时取消航班；总表额外有「不正常原因」。
  • 总表差异：总表 sheet 没有「特服」「出港调时情况航班」列，改为「不正常原因」「出港调时架次」（= 调时航班数）；正常率名为「分公司始发 / 起飞正常率」，取消名为「…架次」。复制总表行时自动按总表列序输出，无需你手动对齐。
  • 逐行复制：东上联表头有「复制东上航」「复制联航」，总表表头有「复制总表」，均按对应 sheet 的精确列序复制整行（Tab 分隔），粘到共享文档对应 sheet 的数据区（B 列起）即可。

1 导入 FIOS 航班表（自动算架次 / 特服 / 调时 / 取消）

拖入或选择当日 FIOS 导出的 Excel，系统按航班号区分东上航司 / 中联航，统计各维度。

2 录入东航 / 上航 / 中联航运量（自动汇总旅客 / 行李 / 客座率）

填写国际 + 国内合计值（与国际出港值分开填）。单元格支持四则运算，如 11+65+231、16*78/15；空值按 0 计。

3 汇总结果（东上航 / 联航 一块，总表单独一块）

东上航、联航共用 24 列表；总表列序不同，单独成块。自动列（白底）由上方数据计算；黄色底为需你手填的列，可直接在格内修改。完成后逐行复制到共享文档，或导出整合 Excel。
