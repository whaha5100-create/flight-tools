使用须知

长期有效

部署在 GitHub Pages（公开仓库），链接长期有效、不会回收，可随时打开使用。

离线可用

依赖的 SheetJS 已打包进各工具目录的 libs/，公司网络屏蔽外部 CDN 也能正常运行。

加密文件

系统导出的名单若带密码，直接在「国际名单转化」页的密码框里填入即可转换，无需手工去密码。

规则口径

各工具的转换 / 分配 / 统计 / 计算规则，详见每个工具页内的「规则说明」面板，口径以页面规则为准。
