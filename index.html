🔒 使用须知 & 数据安全 ▾
  • 纯前端运行：所有计算都在你自己的浏览器里完成，Excel / 名单文件不会被上传到任何服务器，数据只留在本地。
  • 长期有效：本站由 WorkBuddy 部署至 GitHub Pages（公开仓库），链接长期有效、不会回收，可随时打开使用。
  • 离线可用：依赖的 SheetJS 库已打包进各工具目录的 libs/，即使公司网络屏蔽外部 CDN 也能正常运行。
  • 加密文件：浏览器版 SheetJS 不支持读取带密码的 Excel；如遇加密名单，请先在本地用 Excel「另存为」转出无密码版本再上传。
  • 规则口径：各工具的转换 / 分配 / 统计 / 计算规则，详见每个工具页内的「规则说明」面板（可点击展开），口径以页面规则为准。
