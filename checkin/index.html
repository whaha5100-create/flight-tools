规则 值机数据制作规则说明 点击展开点击收起
系统读取 FIOS 导出的出港航班 Excel，按下列规则排出《东上联自助值机数据表》：
  • 取数范围：只取「出港航班」列非空的行；进港航班不进表（进港不涉及值机）。
  • 剔除取消：机号为 CNL / DEL 的航班整行剔除，不计入表格。
  • 剔除国际：到站为 马德里 / 罗马 / 曼谷 的国际航班整行剔除，本表只统计国内航班。
  • 航司分组：MU / CES 开头归东航，FM 开头归上航，KN 开头归中联航；其余航司不进表。
  • 排序：每个分组内按计离时间从早到晚排列；分组顺序为 东航 → 上航 → 中联航。
  • 小计行：依次给出 MU 合计、FM 合计、东上航合计（= 东航 + 上航）、KN 合计；各列均为该组求和。
  • 自助率：自助率 =（WEB + CUSS）÷ 人数；人数为空或为 0 时留空不显示。
  • 航班号符号：FIOS 在航班号后带的 # / & 是系统标记，出表时自动去掉。
  • 数据填写：WEB / CUSS / 人数 由你直接填（FIOS 导出里没有这三列）；不填就导出空白。
  • 导出：一键导出 Excel —— 标题行与合计行文字跨列合并，自助率与合计行均为活公式，在 Excel 里改数会自动重算。
