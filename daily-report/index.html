📌 使用说明
  • 只需填原始数：正常性数据每组只填「航班量 + 正常数 + 机场正常率」，其余比率、差异值、整体列全部自动算。
  • 明细表支持整块粘贴：在表格任意格子里按 ⌘V，从 Excel 复制的整块数据会自动按行按列铺进去。
  • 值班安排：点岗位旁的「A 组 / B 组 / C 组」一键套用轮转模板，再点人名上的 × 或输入框手动增减。
  • 导出 Word：生成真正的 .docx（页眉页脚每页重复、页码是真域、表格带边框底纹），可直接编辑。
