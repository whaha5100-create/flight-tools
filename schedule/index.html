规则 排班表规则说明 点击展开点击收起
导入出港航班 Excel 后，系统按下列规则自动生成可编辑排班表：
  • 只取出港航班：仅读取出港方向航班，自动跳过进港及取消记录（机号为 CNL / DEL）。
  • 两个班次分开排：一个班次从当天 08:30 干到次日 08:30。顶部可切「第一天 / 第二天」，各自导入一份 FIOS 表（一次只能导一天）。第一天只留 08:30 之后的航班，第二天只留 08:30 之前的航班；两份互不影响，导出也是各自一份。
  • 按计离排序分段：全部航班先按「计离」从早到晚排序，再按早 / 午 / 晚三段分组。三个时间都可以自己改（默认 上班 0830 / 早→午 1400 / 午→晚 1830）：改「上班」会同时改变第一天与第二天怎么切分，改另两个只挪早午晚的分界。改完立即重算，并记在本机。
  • 登机口：点格子里的号码，弹出 201–224 的号码格，点哪个填哪个；底部可以手输（超出 201–224 也能填），也能一键清空。
  • 负责人选择：点格子内「＋ / 添加」展开选择器，勾选名单里的人，或当场输入新姓名添加。一个航班最多 3 个负责人；名单长了弹层顶部有搜索框。
  • 人员名单（能加也能删）：表格下方的「人员名单」就是全部人员的花名册，从空白开始、完全由你自己维护。
    ① 加：在「添加姓名，回车」框里打完名字回车即可；
    ② 搜：左边搜索框打两个字就能定位（几十个人也不用翻）；
    ③ 删：点名字后面的 ×，会问你两种 —— 「只从这一班去掉」（他还留在名单里，明天照样能勾）或 「从名单彻底删掉」（所有班次里一起清掉，颜色也删）。
    名单人数多时这一块内部滚动，不会把页面拉长；名单记在本机。
  • 负责人配色：名字前面那个圆点就是各人的颜色，只用来区分人、不占版面。出厂状态所有圆点都是白的，颜色由你在「人员名单」里自己点（点色块挑色，可随时换）。「全部恢复出厂」把圆点全部变回白色、底色字色一起还原，可撤回。颜色不存本机，刷新后回到白点。
  • 表格字体：字号 / 加粗 / 字体作用于整张表。列宽会跟着字号等比放大，所以放大不会串列、也不会把四字站名截断；导出的图片同步放大。选择记在本机。
  • 导出配色：默认纯白底 + 近黑字。也可自选底色与字色，表头、发丝线、输入框描边由这两个颜色自动推导；选完立刻在页面上生效，导出的图片同一套配色。右边的「恢复默认」只还原底色和字色，「全部恢复出厂」是连圆点一起还原。所选配色会记住，下次打开仍生效。
  • 撤回：改颜色、恢复配色、删行、插行、改登机口、改备注都能撤回，按 ⌘Z / Ctrl+Z 或点「撤回」，最多 20 步。
  • 高客座提醒：订座里那三个数字是三舱人数，系统只把它们加起来判断：合计超过 160 就在备注最前面打上「高客座」，不用自己算，也不再单占一列。
  • 备注列顺序：备注自动按「高客座 → 预推时间 → 特服 → 航班调时」拼接展示，便于快速读取保障要点。
  • 本地草稿：编辑后可在本机保存草稿，下次打开可「读取上次草稿」继续；两天各存一份。
  • 导出：支持导出当前班次当前时段 / 当前班次全部时段为 Excel，以及导出排班图为图片，便于发群或打印。
