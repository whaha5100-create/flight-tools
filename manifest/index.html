规则 转换规则说明 点击展开点击收起
系统按表头名称自动识别各列，将原始名单清洗、映射为标准「海关旅客订票数据上传模板」。下方为关键处理规则：
  • 自动识别列：按表头名称匹配 航班日期 / 实际承运人 / 实际航班号 / 起飞地 / 目的地 / 名称 / 性别 / 生日 / 国籍 / 证件号码 等字段，列序不同也能正确解析。
  • 国籍代码：二字码自动转三字码（CN→CHN、US→USA），并修正常见错别字；无法识别的国籍标黄提示你手动核查。
  • 性别代码：1→M、2→F，也直接支持 M / F。
  • 证件号码：去除开头的多余符号（- , 等），并按 / 取第一段。
  • 出生日期：统一清洗为标准 YYYY-MM-DD 格式。
  • 出入境判定：依据航班号——单号出境、双号入境：MU261 / MU751 记为出境，MU262 / MU752 记为入境；FM883 记为出境，FM884 记为入境。
  • 往来机场代码：输出英文 IATA 三字码——MU261 / MU262 为 MAD（马德里），MU751 / MU752 为 FCO（罗马），FM883 / FM884 为 BKK（曼谷）；其它航班取非温州那一端的机场代码。
  • 上报口岸：固定写入 050-温州机场。
  • 不完整记录：姓名 / 证件号 / 国籍 / 性别 / 生日 任一缺失的旅客行将被跳过，并在结果中单独列出，方便你补录。
  • 输出文件：生成「航班订票数据上传模板」格式 .xlsx（标题行 + 15 列表头 + 旅客数据行），可直接下载上传。
